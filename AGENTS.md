# AGENTS.md

## Project

CAMU Taekwondo Landing Page.

## Before making changes

Read:

1. `.agents/project-context.md`
2. `.agents/architecture.md`
3. `.agents/design-system.md`
4. `.agents/content.md`
5. `.agents/coding-rules.md`
6. `.agents/continuation.md`

## Rules

- Do not rewrite the architecture without reason.
- Do not remove existing sections without explicit instruction.
- Preserve responsive behavior and the design system.
- Reuse components and keep content separated from presentation.
- Do not invent real-world information.
- Update documentation after significant architectural changes.
- Run `npm run build` after implementation changes.

## When completing a task

Update `.agents/continuation.md` with what changed, what remains, known issues and next recommended task.
