# Project Context

## CAMU

CAMU es un club de Taekwondo. La landing presenta su propuesta y facilita que las personas interesadas soliciten una clase demo.

## Goal

Construir una experiencia oscura, deportiva, editorial y responsive, guiada por `Pagina.pdf` y por el contenido que el usuario transcribió en su prompt.

## Stack

Vue 3, Vite, TypeScript, Composition API y CSS. Sin Vue Router ni dependencias de animación.

## Structure

Las secciones viven en `src/components`, los datos repetibles en `src/data` y los estilos globales en `src/styles`.

## Current status

Landing implementada con navegación móvil, hero, principios, institucional, sedes, galería con lightbox, entrenamiento, instructores, formulario visual y footer. SEO básico, layout responsive y respeto a `prefers-reduced-motion` incluidos.

## Pending

Revisar el PDF visualmente para cotejar los textos institucionales, sustituir imágenes temporales, confirmar direcciones y contactos y conectar el envío del formulario.
