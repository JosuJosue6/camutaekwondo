# Coding Rules

- Use Vue 3 Composition API and TypeScript.
- Prefer small components; avoid monolithic `App.vue`.
- Keep repeated content in `src/data`; do not duplicate data in templates.
- Keep imagery in the configuration modules and provide useful alt text.
- Preserve semantic HTML, keyboard access, visible focus, and contrast.
- Maintain mobile layouts and avoid horizontal overflow.
- Do not add dependencies without a clear need.
- Do not invent CAMU facts, locations, credentials or contact details.
- Respect `prefers-reduced-motion`.
- Update this context after significant architecture changes and run `npm run build`.
