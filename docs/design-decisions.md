# Design Decisions

- Barlow Condensed gives headlines a compact athletic poster voice; DM Sans keeps utility text readable.
- Charcoal, warm white and a single lime accent establish contrast without a generic gym palette.
- Image overlays, grayscale treatment, large type and ruled lists form the cinematic editorial language.
- One-page anchors avoid unnecessary routing complexity.
- Motion uses CSS and IntersectionObserver with a reduced-motion override.
